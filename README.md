## What Is Blockspace?

Blockspace is a Minecraft-inspired voxel environment whose terrain and structures are generated procedurally. The setting begins with a generated voxel island and extends into maze-like formations derived from triply periodic minimal surfaces, including the gyroid family of mathematical surfaces.

Everything runs in a WebGL2-capable browser. The project is provided as a dependency-free HTML demo and combines procedural materials, interactive traversal, voxel-based movement, and a world that repeats continuously through periodic wrapping.

## Frequently Asked Questions

### Can Blockspace be installed as a desktop program?

No. Blockspace is intended to run inside a web browser with WebGL2 support.

### Are any extra libraries needed?

No. The demos are standalone HTML files and have no dependencies.

### How does Blockspace create its environments?

The world is generated procedurally as a voxel island, with additional structures formed from triply periodic minimal surfaces such as gyroid-style mathematical forms.

### Which movement mechanics are included?

Movement includes voxel collision, gravity, jumping, swimming, and flight.

### Is the world enclosed by a normal edge?

No fixed edge stops movement. Periodic wrapping connects the world across its boundaries so travel can continue into repeating regions.

### Why might the demo fail to display?

First verify that the browser provides WebGL2 support, then reload the HTML file or test it in a current browser. The browser may also need hardware-accelerated graphics enabled for WebGL2 rendering.
